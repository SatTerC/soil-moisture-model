# Getting Started

## Installation

Install the package via `pip` or `uv`.

=== "pip"

    ``` sh
    pip install git+https://github.com/SatTerC/soil-moisture-model
    ```

=== "uv"

    ``` sh
    uv add git+https://github.com/SatTerC/soil-moisture-model
    ```

## Basic usage

```python
from soil_moisture_model import main

# Your code here
result = main()
print(result)
```

See the [API Reference](API_Reference/soil_moisture_model.md) for full documentation.
